# JavaScript Course

A personal learning repository dedicated to learning **JavaScript** and practicing web development.

This repository contains code examples, exercises, and small projects created while studying JavaScript, HTML, CSS, and modern frontend development concepts.

## 📚 Topics Covered

The repository is organized into folders by topic to make learning and navigation easier.

- **Variables and Data Types** — variables, primitive types, type conversion, and operators.
- **Functions** — function declarations, expressions, arrow functions, parameters, and return values.
- **Arrays and Objects** — working with collections of data and object properties.
- **Control Flow** — conditions, loops, and logical operators.
- **DOM Manipulation** — selecting HTML elements and dynamically updating page content.
- **Events** — handling user interactions and form submissions.
- **Asynchronous JavaScript** — promises, `async/await`, and working with APIs.
- **HTTP Requests** — using `fetch()` to retrieve and send data.
- **CRUD Operations** — creating, reading, updating, and deleting data.
- **Modules** — organizing JavaScript code into reusable modules.
- **Git and GitHub** — version control and repository management.

## 🚀 Projects and Practice

The repository may also include practical exercises and small applications, such as:

- **Exchange Rates App** — retrieving and displaying currency exchange rates.

## 💻 Getting Started

To explore the code locally, clone the repository:

```bash
git clone https://github.com/RuslanG13/javascript_course.git
```

Navigate to the project directory:

```bash
cd javascript_course
```

Open the project in your preferred code editor, such as Visual Studio Code.

Most basic examples can be opened directly in a browser. Projects that use JavaScript modules or API requests may require running a local development server, such as the VS Code Live Server extension.
